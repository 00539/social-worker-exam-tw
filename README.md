# 社工師刷題本

**線上使用 → <https://00539.github.io/social-worker-exam-tw/>**

專門職業及技術人員高等考試「社會工作師」考古題庫與備考工具。

把考選部公布的 **106–115 年、20 次考試、115 份考卷** 全部解析成結構化資料，
產出一個可離線使用的網頁刷題本，以及一份以統計數據為基礎的備考指南。

| 項目 | 數量 |
|---|---|
| 測驗題（單選） | 4,600 題 |
| 申論題 | 230 題 |
| 考卷份數 | 115 份 |
| 考點索引 | 158 個 |
| 已核對法規 | 16 部 |

---

## 這個專案跟「把 PDF 丟上網」差在哪

1. **答案是可信的**：測驗題答案以考選部最新公告之「更正答案」為準，
   「一律給分」「多重答案均給分」的題目都已個別處理。
2. **錯題依考點聚合**：答錯「案主自決」，就把題庫裡 20 幾題相關考題連同正解一起攤開，
   而不是只告訴你這題選 C。
3. **法規已修正的題目會被擋掉**：比對 16 部主要法規的最新修正日期，
   凡是「考試日期早於該法最近一次修正」的題目預設不出題，避免背到舊制。
4. **備考規劃連動作答紀錄**：依考選部公告的考試日期倒數，
   依你各科的實際正確率決定本週主攻哪一科。

## 快速開始

### 需求

- Python 3.10 以上
- Windows（下載腳本用 PowerShell 寫的；解析與打包腳本跨平台）

```bash
pip install -r requirements.txt
```

### 1. 下載考選部試題

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dl2.ps1   # 106–110 年
powershell -ExecutionPolicy Bypass -File scripts\dl.ps1    # 111–115 年
```

PDF 會放在 `data/papers/<年度次別>/`，約 273 個檔、49 MB。
這些檔案**沒有**進版控（見 `.gitignore`），需要時重跑腳本即可。

### 2. 解析與打包

```bash
cd scripts
python extract.py         # 測驗題 → build/questions.json
python extract_essay.py   # 申論題 → build/essays.json
python tag.py             # 標上考點
python lawcheck.py        # 標上法規時效
python build_data.py      # 打包 → app/questions.js
```

### 3. 打開網頁

```bash
python scripts/serve.py
```

瀏覽器開 <http://127.0.0.1:8766>。

`app/` 是純靜態的兩個檔案，丟到任何靜態主機或直接用瀏覽器開都能跑，
不需要後端，也不會把任何資料傳出去。

### 部署

推到 `main` 且異動到 `app/` 時，`.github/workflows/pages.yml` 會自動把 `app/`
部署到 GitHub Pages。也可以到 Actions 頁面手動觸發（workflow_dispatch）。

### 4.（選用）重新產生備考指南

```bash
python scripts/make_guide.py    # → docs/社工師備考指南_十年考古題分析.docx
```

## 解析是怎麼做的

考選部的試題 PDF 有幾個不明顯的坑，這裡記下來避免以後重踩：

- **選項標記是造字區字元**。``–`` 對應 Ⓐ–Ⓓ，
  ``–`` 對應 ㈠–㈤，``–`` 對應 ①–④。
  這些編碼跨全部 115 份考卷一致，所以可以精準切出選項邊界，不需要猜。
- **中西文基線不同**。`3 日` 這種選項裡，數字與中文的 y 座標差約 1pt，
  用 y 座標分列時必須抓垂直中心並給 5pt 容差，否則數字會掉到別列去。
- **頁首會被拆成兩個文字片段**。`代號：` 與 `10360` 是分開的 span，
  只濾單一 span 的話 `10360` 會黏進選項尾巴。必須整列比對後整列剔除。
- **更正答案的備註寫法有好幾種**。`第N題答Ｄ給分`、`第N題答Ａ或Ｂ或AB者均給分`、
  `第N題除未作答者不給分外，其餘均給分`、`第N題一律給分`，且會跨行斷開。

`scripts/check.py` 會檢查選項數、空選項、造字殘留、答案格式，
目前 4,600 題只剩 1 筆「異常」，是一個正常的單字選項（`愛`）。

## 考點索引的限制

考點是**依題幹與選項用詞自動歸類**的，不是考選部的官方分類。

- 可歸類率：測驗題 76.3%、申論題 75.2%
- 歸不到的題目會集中在「未歸入既有考點」，不會被丟掉
- 詞典寫在 `scripts/concepts.py`，可自行增修

寫詞典時要小心過泛的詞。例如把「自我」當成 Freud 精神分析的比對詞，
會誤中「自我決定」「自我效能」「自我概念」，讓命中數從 60 暴增到 171。

## 法規時效機制

判定規則：**題目明確引用某部法規名稱，而該法在這場考試之後又修正過**，
再依「那次修法實際改了多少條文」分成三級。

分級很重要。一開始只要修過法就整批排除，結果誤砍：身心障礙者權益保障法
114/08/01 只改了第 53 條（無障礙運輸），卻讓 39 題全被擋掉。逐條查證沿革後，
214 題裡真正高風險的只有 62 題。

| 等級 | 判準 | 預設行為 |
|---|---|---|
| high | 全文修正，或法規更名 | 不出題 |
| mid | 修正十餘條 | 照出，標示提醒 |
| low | 只動一兩個條文 | 照出，標示提醒 |

已核對 **24 部**法規，修正日期與條文範圍於 2026-09-23 逐條查自全國法規資料庫沿革。
納入標準：題庫引用 8 次以上的法規全部涵蓋。

**要講清楚的三件事：**

1. 修法未必動到被考的那一個條文，所以這是「避開高風險」，不是「這題一定錯」。
2. 只在題目寫出法規名稱時才比對。談概念而不引條文的題目不會被標記，
   這是刻意的——否則會誤砍幾百題。
3. 三部國際公約（CRPD、CRC、CEDAW）的本文由聯合國訂定，不隨國內修法變動；
   這裡追蹤的是其施行法。考題多半測公約本身的內容，因此風險極低。

要找出還沒納入的法規，執行 `python scripts/findlaws.py`，
它會統計候選法規在題庫中的實際引用次數。

法規會持續修正，`scripts/lawcheck.py` 裡的日期與範圍需要定期更新。

## AI 解題指令

本站是純靜態網頁，**沒有後端也沒有 API 金鑰**（金鑰放進公開前端等於外流）。
所以不會自動呼叫 AI，改成一鍵組出完整指令讓使用者自己貼到 AI 對話視窗。

指令會自動帶入：題目原文、四個選項、考選部公告正解、使用者的作答、
本站考點標記，以及該題的法規時效狀態（哪部法、何時修正、改了哪些條文、風險等級）。
並且要求 AI 先查證現行條文，明確說明「當年答案」與「現行規定」是否一致。

申論題則帶入題目、配分與使用者的擬答，套用批閱格式輸出評分、失分分析與重構範文。
格式模板定義在 `app/index.html` 的 `AI_RULES` / `AI_MC_FORMAT` / `AI_ESSAY_FORMAT`，可自行調整。

## 申論題為什麼沒有「參考答案」

**考選部只公布申論題題目，不公布標準答案，也不公布評分標準。**
所以這個專案不提供逐題範答——自己生成 230 題擬答放到公開網站，
等於把未經查證的內容當成答案給人背，法規細節錯了會直接害到考生。

改成提供**可查證的參考材料**，每題申論題底下有「作答參考」區：

1. **同考點測驗題的官方正解**（最多 12 題）
   這些是考選部公告的答案，可以直接當知識點核對。
   申論題與測驗題的考點重疊度很高，這是目前最可靠的參考來源。
2. **歷年同主題申論題**（最多 6 題）
   同一主題會以不同情境反覆出現，看過就知道問法怎麼變。
3. **通用答題架構**（定義 → 理論依據 → 分項回答 → 連結情境）
4. **AI 批閱**：把題目、配分與自己的擬答組成指令，讓 AI 做評分與重構示範

未歸入考點的申論題（約 25%）沒有第 1、2 項，會提示直接用 AI 批閱或回原卷對照。

## 新考試公布後怎麼更新

1. 在 `scripts/dl.ps1` 的 `$exams` 加一筆新場次（考試代號可在考選部考畢試題查詢平臺的下拉選單取得）
2. 依序跑 `extract.py` → `extract_essay.py` → `tag.py` → `lawcheck.py` → `build_data.py`
3. 更新 `scripts/lawcheck.py` 的法規修正日期
4. 更新 `app/index.html` 裡的 `TARGETS`（下一次考試日期）

本專案為個人備考用途整理，不代表考選部立場，也不保證解析結果完全無誤。
法規類題目可能因法條修正而與現行規定不同，**作答與實務應用請以現行條文為準**。
